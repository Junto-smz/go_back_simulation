# 帰省コストシミュレーション「かえりみち」

京都を起点に、目的先の都道府県と年間の帰省回数から交通費・移動時間を計算する静的Webページです。フレームワークやパッケージのインストールは不要です。

## 起動

プロジェクト直下で次のコマンドを実行してください。

```powershell
python -m http.server 8000
```

ブラウザーで http://localhost:8000 を開きます。終了はターミナルで `Ctrl+C`。

JSONを `fetch` で読むため、HTMLをダブルクリックするのではなくHTTPサーバー経由で開いてください。日本語フォントを取得できない場合も、端末の標準フォントで利用できます。

## データと計算

- データ元はプロジェクト直下の `cost.json`。選択肢はJSONのキーから生成します。現在は京都府を除く46都道府県です。
- `cost` を1回の帰省の往復交通費（円）、`minutes` を往復移動時間（分）として扱います。JSON自体には往復・片道のメタデータがないため、この前提を画面にも明記しています。
- 年間交通費 = `cost × 帰省回数`
- 年間移動時間 = `minutes × 帰省回数`
- 月あたりの交通費 = `年間交通費 ÷ 12`（表示時に円単位に四捨五入）
- 回数は0以上の整数。0回では年間の合計は0となり、1回あたりの内訳は表示します。
- 宿泊費・現地での移動費などは含みません。

初期値は東京都・年3回です。目的先の変更、数値入力、増減ボタン、回数の候補ボタンで結果が即時更新されます。
